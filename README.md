# 귀로걷다 (Earwalk) — Android 베타 내려받기

시각장애인을 위한 보행 보조 앱 **귀로걷다**의 설치 파일(APK)과 변경 안내만 두는 곳입니다. 소스 코드는 여기 없습니다.

- 소개·이용 신청: https://earwalk.eond.com
- 설치 안내: https://earwalk.eond.com/ko/install
- 최신 판 바로 받기: https://github.com/eondcom/earwalk/releases/latest/download/earwalk.apk

## 사용하려면
1. 위 주소에서 APK 를 받아 설치합니다(처음 한 번 "출처를 알 수 없는 앱 허용"이 필요합니다).
2. 앱을 켜고 언어를 고른 뒤 **구글 계정으로 시작**을 누릅니다.
3. 베타 기간에는 승인된 계정만 쓸 수 있습니다. 승인 전이면 "신청이 접수됐어요"라고 안내합니다.

## 꼭 알아 두세요
AI 안내는 틀릴 수 있습니다. 흰지팡이·안내견을 대신하지 않으며, 신호등·차도는 반드시 주변 소리와 직접 확인으로 판단하세요.
